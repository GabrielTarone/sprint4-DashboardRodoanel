## Como executar o projeto

### Requisitos

- Navegador moderno, como Google Chrome, Microsoft Edge ou Firefox.
- Conexão com a internet.
- Não é necessário instalar dependências ou bibliotecas do projeto.

### Instruções de execução

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code ou em outro editor de sua preferência.
3. Abra o index.html com a opção de "Open with live server" ou com o navegador que preferir.
4. O dashboard será carregado automaticamente.

**Observação:** a conexão com a internet é necessária para carregar os mapas, as bibliotecas utilizadas pelo dashboard e os dados meteorológicos da Open-Meteo.
